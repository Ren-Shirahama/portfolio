Skills

HTML/CSS

Figmaで作成したデザインカンプをもとに、PC・スマホに対応したコーディング（レスポンシブ対応）が可能です。元のデザインカンプをWeb上で正確に再現すること、そして誰が見ても分かりやすく崩れにくい丁寧な実装を心がけています。

JavaScript

現在は基本的な知識をベースに、Webサイトに動きやアニメーションをつける実装（ハンバーガーメニューやスライダーなど）に向けて、さらに学習を深めています。

WordPress

基本的な操作や、固定ページ・投稿ページの作成が可能です。今後はさらに表現の幅を広げるために、自分で1からオリジナルのサイトを組み立てられるよう知識を深めています。

PHP

Webサイトのフォーム機能や動的な仕組みを理解するため、現在は基本的な文法やデータ処理などの基礎から学習を進めています。

Figma

レイアウト、配色、文字組みなどを組み合わせ、サイトの目的やターゲットの雰囲気に合わせたデザインを作成することができます。今回のポートフォリオもすべてFigmaで設計しました。

Canva

基本的な機能を一通り使用でき、サイトの目的に合わせてバナーやSNS用画像などのデザインを作成・調整することができます。
